# 🧮 Calculadora Kotlin

Uma aplicação de calculadora desenvolvida em **Kotlin**, focada na prática dos conceitos fundamentais da linguagem, lógica de programação e estruturação de código.

---

## 🚀 Funcionalidades

- ➕ **Adição**
- ➖ **Subtração**
- ✖️ **Multiplicação**
- ➗ **Divisão** (com tratamento para divisão por zero)

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** [Kotlin](https://kotlinlang.org/)
- **IDE recomendada:** IntelliJ IDEA / Android Studio
